# AAPS 4.0.0 with a few changes

This is a fork of [AAPS](https://github.com/nightscout/AndroidAPS) with these changes:

1. Steps from the watch. A Garmin watch face can send your steps to AAPS.
2. Push watch face. AAPS tells the Garmin watch face when there is new data.
3. Garmin remote control. Commands from the watch with the AAPS Control widget.
4. English (UK). A new app language. Dates are shown as day/month/year, for example 09/11/2026.

> This is experimental. Do not use it to dose insulin unless you understand and accept the
> risks. Use at your own risk.
